# RailConnect — Railway Reservation Website

A beginner-friendly static web application for a student CI/CD assignment.

## Features
- Train search form with source, destination, journey date, and passenger count
- Sample train results and estimated demo fares
- Demo ticket confirmation (no real tickets, payments, or railway data)
- Responsive layout for desktop and mobile

## Run locally
1. Extract the project ZIP.
2. Open `index.html` in a web browser.

No build step or package installation is required for the initial version.

## Project files
- `index.html` — page structure
- `style.css` — layout and responsive styling
- `script.js` — sample train search and demo booking interactions

## CI/CD assignment note
This is a demo project, not an official railway reservation service. Later, add the Dockerfile, Jenkinsfile, and Kubernetes manifests for the CI/CD pipeline.
